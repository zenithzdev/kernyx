# KERNYX

[![CI](https://github.com/zenithzcloud/kernyx/actions/workflows/ci.yml/badge.svg)](https://github.com/zenithzcloud/kernyx/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**KERNYX** — Adaptive Linux Performance Optimization Engine.

## One-command installation (first time)

```bash
curl -fsSL https://zenithzdev.github.io/kernyx-apt/install.sh | sudo bash
```

The script detects your distro/architecture, verifies the pinned GPG key
fingerprint, configures the signed APT repository, and installs KERNYX.

## Normal installation / updates / removal

```bash
sudo apt install kernyx
sudo apt update && sudo apt upgrade
sudo apt remove kernyx
```

## Supported systems

- Ubuntu 20.04, 22.04, 24.04, 26.04
- Debian 11, 12, 13
- Linux Mint, Pop!_OS
- Architectures: amd64 (ARM64 packages are generated by the release workflow)

## Commands

```bash
kernyx detect          # or: kernyx d
kernyx analyze         # or: kernyx a
kernyx optimize        # or: kernyx o
kernyx optimize --dry-run
kernyx status
kernyx report
kernyx doctor
kernyx rollback
kernyx history
kernyx config show
kernyx config validate
kernyx cpu | memory | process | network | storage | services | security | health
kernyx benchmark -- <command>
kernyx monitor         # bundled btop
kernyx fetch           # bundled fastfetch
kernyx version
```

## Bundled upstream tools

KERNYX packages include real upstream binaries; no separate installation is needed:
- btop (`kernyx monitor`)
- fastfetch (`kernyx fetch`)
- hyperfine (`kernyx benchmark`)

Licenses are preserved in `third_party/` and `vendor/btop/`.

## Repository signing

APT metadata is GPG-signed. The public key is published at:
`https://zenithzdev.github.io/kernyx-apt/kernyx.asc`

Pinned fingerprint:
`864FE821DCAF96A4B8F9F71EFB1D9A2606C3F536`

APT uses modern `signed-by=` keyring configuration; `trusted=yes` and
deprecated `apt-key` are never used.

## Troubleshooting

- `apt update` fails signature check: re-download the key or check the fingerprint.
- `kernyx` command not found after install: run `hash -r` or reopen your shell.
- `kernyx monitor` requires an interactive TTY.
- Unsupported distro: open an issue at https://github.com/zenithzdev/kernyx/issues

## GitHub Releases

Releases are published at https://github.com/zenithzdev/kernyx/releases
and contain `.deb` packages plus SHA256 checksums.

## Build from source

```bash
cargo build --release
sudo install -m 755 target/release/kernyx /usr/bin/kernyx
```
